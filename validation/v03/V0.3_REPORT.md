# OPTIVANCE V0.3 — Rapport d'avancement bloqué sur prérequis

**Date :** 12 novembre 2026  
**Statut :** mission non terminée; aucune fonctionnalité V0.3 n'a été implémentée.  
**Phase 1 :** non commencée et non autorisée.

## Résumé exécutif

L'audit du module Storage V0.2 est terminé et un protocole de validation a été pré-enregistré. Le premier essai d'accès MFT a été fait sous le jeton standard, après confirmation que `C:` est NTFS. L'ouverture directe de `\\.\C:` a échoué avec l'erreur Win32 5 (accès refusé); `FSCTL_ENUM_USN_DATA` n'a donc pas été appelé. Aucune élévation n'a été déclenchée.

La documentation Microsoft stipule que l'accès direct à un volume requiert des privilèges administrateur. La poursuite de l'essai MFT sur le volume réel exige donc une autorisation explicite d'élévation ponctuelle. Par ailleurs, le poste dispose du runtime Desktop .NET 10.0.15 mais aucun SDK .NET n'est détecté; la compilation et la validation de l'interface WPF requièrent une installation du SDK. Conformément aux consignes, aucune installation n'a été faite.

Ces prérequis bloquent la production d'un V0.3 compilable, le prototype MFT sur volume réel, les tests WPF et le benchmark complet. L'audit et les éléments documentaires disponibles sont dans [V0.3_AUDIT.md](V0.3_AUDIT.md) et [V0.3_VALIDATION_PROTOCOL.md](V0.3_VALIDATION_PROTOCOL.md).

## Autorisations nécessaires pour continuer

1. Autoriser explicitement un essai d'énumération MFT **ponctuellement élevé et en lecture seule**, sur un volume NTFS indiqué, via consentement UAC après action explicite; sans service, driver, écriture, changement d'ACL/journal, ni élévation de l'interface.
2. Autoriser l'installation du **SDK .NET 10 x64** nécessaire pour compiler et vérifier WPF. Le runtime Desktop seul ne permet pas la compilation; aucune dépendance applicative ou package tiers n'est demandé.
3. Pour produire les livrables demandés, fournir ou autoriser plus tard l'accès à une VM Windows 10 Enterprise LTSC 2019 si une validation spécifique à cette cible est attendue. À défaut, toute compatibilité LTSC restera explicitement non vérifiée.

La comparaison WizTree MFT peut également demander l'élévation. Elle ne sera pas lancée en mode administrateur sans la même autorisation explicite. Le benchmark antérieur reste une référence historique et ne satisfait pas la comparaison demandée.

## Verdict provisoire

**V0.3 non réalisé.** L'audit est terminé, mais aucune refonte ni preuve de prototype n'est revendiquée. La mission est en pause au point où les deux blocages concrets apparaissent (accès volume administrateur et SDK absent). La Phase 1 n'a pas commencé.

## Mise à jour — mission d’intégration MFT/UAC du 12 novembre 2026

La nouvelle mission autorise explicitement un helper MFT distinct, une demande UAC à chaque action MFT et le fallback classique. Elle est cohérente avec D-06; le backend FSCTL reste expérimental et n’est pas déclaré comme décision finale. Le plan détaillé figure dans [MFT_UAC_INTEGRATION_PLAN.md](MFT_UAC_INTEGRATION_PLAN.md).

Le SDK indiqué a été trouvé : `dotnet --list-sdks` retourne `10.0.404` et `dotnet --version` retourne `10.0.404`. `Optivance.Core` compile en Release (0 avertissement, 0 erreur). Le build de `Optivance.Desktop` n’atteint pas la compilation C# : MSBuild ne résout pas les SDK workload locators `Microsoft.NET.SDK.WorkloadAutoImportPropsLocator` et `Microsoft.NET.SDK.WorkloadManifestTargetsLocator` (MSB4276), leurs répertoires attendus étant absents de l’installation détectée. `dotnet --info` échoue également lors de sa tentative de lecture du Service Control Manager. Aucun contournement de l’environnement ou réparation du SDK n’a été effectué.

À ce stade, aucun fichier source applicatif n’a été modifié; aucune UAC, énumération MFT, test UI ou benchmark n’a été exécuté. Les seuls changements sont les artefacts de protocole, audit, plan et rapport sous `validation/v03/`. La mission est en attente d’un environnement .NET Desktop/MSBuild correctement initialisé ou d’une autorisation de réparer l’installation du SDK. Aucun consentement UAC n’a été demandé.
